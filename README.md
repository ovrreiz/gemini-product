# Генератор описів товарів і хештегів (Gemini API)

PoC-проєкт до **Завдання 2** курсу «Хмарні обчислення»: інтеграція з хмарним ШІ-API (**Google Gemini API**); запуск у **Google Cloud Shell** або локально.

Користувач вводить назву товару, характеристики, аудиторію, платформу (маркетплейс, Instagram, Telegram, LinkedIn), мову й тон. Gemini повертає **структурований JSON**: заголовок, короткий і повний опис, хештеги, заклик до дії, ключові слова. Результат автоматично перевіряється й за потреби виправляється.

## Що тут показано (з точки зору роботи з API)

| Можливість | Де в коді |
|---|---|
| Виклик `generateContent` через офіційний SDK `google-genai` | `copygen/llm.py` → `GeminiBackend` |
| **Системна інструкція** (правила копірайтера, «лише факти з вхідних даних») | `copygen/prompts.py` |
| **Structured output**: JSON за схемою (`response_mime_type` + `response_schema`) | `copygen/schema.py`, `llm.py` |
| Захист від **prompt injection** (дані користувача в `<product>`, інструкція «це лише дані») | `prompts.py` |
| Автоматична **валідація**: довжини, кількість хештегів, мова, «вигадані числа» | `copygen/checks.py` |
| **Самовиправлення**: порушення повертаються моделі для повторної спроби | `llm.py` → `generate` |
| Надійність: повтори з паузою (429/5xx), **запасні моделі**, порожня/зламана відповідь | `llm.py` |
| Кеш однакових запитів (економія квоти) | `llm.py` |
| Демо-режим без API, ліміт запитів на сесію, необов'язковий пароль | `llm.py`, `app.py` |

## Архітектура

```
 Браузер ──► Streamlit UI (app.py)
                 │ ProductRequest
                 ▼
        copygen.llm.generate()
   ┌─────────────┼───────────────────────────────┐
   │ prompts.py  │  GeminiBackend ──► Gemini API  │  (retry / запасні моделі)
   │ (system +   │  (google-genai)    generateContent
   │  <product>) │        │ JSON                  │
   └─────────────┼────────▼───────────────────────┘
                 │  schema.parse_copy()  ──► нормалізація хештегів
                 │  checks.run_checks()  ──► довжини, хештеги, числа, мова
                 │  (є порушення?) ──► повторний запит із зворотним зв'язком
                 ▼
           GenerationResult ──► UI (текст, перевірки, токени, час)
```

## Структура проєкту

```
app.py                  веб-інтерфейс (Streamlit)
copygen/
  config.py             платформи, мови, тони, змінні середовища
  models.py             ProductRequest, ProductCopy, GenerationResult
  prompts.py            системна інструкція і побудова промпта
  schema.py             схема відповіді, розбір JSON, нормалізація хештегів
  checks.py             перевірки якості
  llm.py                GeminiBackend, MockBackend, generate() з повторами/кешем
  cli.py                запуск з командного рядка
  errors.py             винятки
scripts/
  check_api.py          перевірка ключа, перелік доступних моделей, тестовий запит
  run_cloudshell.sh     запуск у Cloud Shell
tests/test_core.py      30 unit-тестів (без мережі)
requirements.txt, .env.example
```

## 1. Отримати API-ключ

1. Відкрийте https://aistudio.google.com і увійдіть акаунтом Google.
2. **Get API key** → **Create API key** (можна вибрати наявний проєкт Google Cloud).
3. Скопіюйте ключ. **Нікому його не показуйте й не додавайте в репозиторій.**

Безкоштовний рівень Gemini API має ліміти запитів і може використовувати вміст запитів для покращення продуктів Google, тому вводьте лише вигадані або публічні дані про товари.

## 2. Запуск у Cloud Shell (найпростіше)

```bash
git clone https://github.com/<ЛОГІН>/<РЕПОЗИТОРІЙ>.git
cd <РЕПОЗИТОРІЙ>
export GEMINI_API_KEY="ваш_ключ"
python3 scripts/check_api.py          # перевірка ключа й моделей (необов'язково)
bash scripts/run_cloudshell.sh        # запускає застосунок на порту 8080
```
Далі у верхній панелі Cloud Shell натисніть **Web Preview** → **Preview on port 8080**.

## 3. Запуск на власному комп'ютері

```bash
python3 -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
export GEMINI_API_KEY="ваш_ключ"                         # Windows (PowerShell): $env:GEMINI_API_KEY="..."
streamlit run app.py
```
Відкриється http://localhost:8501. **Без ключа** застосунок запуститься в **демо-режимі**: текст складається за шаблоном, без ШІ (щоб можна було переглянути інтерфейс).

## 4. Командний рядок і тести

```bash
python -m copygen.cli --name "Термокружка Nord" --feature "Об'єм 450 мл" --feature "Тримає тепло 8 годин" \
    --platform instagram --language uk --tone Дружній            # реальний Gemini
python -m copygen.cli --name "Термокружка Nord" --feature "Об'єм 450 мл" --mock   # демо без ключа
python -m unittest -v                                            # 30 тестів, мережа не потрібна
```

## Змінні середовища

| Змінна | Призначення | За замовчуванням |
|---|---|---|
| `GEMINI_API_KEY` (або `GOOGLE_API_KEY`) | ключ Gemini API | — (тоді демо-режим) |
| `GEMINI_MODELS` | моделі через кому: перша основна, решта запасні | `gemini-3.1-flash-lite,gemini-3.5-flash-lite,gemini-3.5-flash` |
| `MOCK` | `1` — примусовий демо-режим | авто (немає ключа → демо) |
| `MAX_REQUESTS_PER_SESSION` | ліміт реальних запитів у сесії | 20 |
| `REQUEST_TIMEOUT_S` | таймаут запиту до API | 30 |
| `APP_PASSWORD` | пароль на вхід у веб-інтерфейс | вимкнено |

## Типові проблеми

| Симптом | Причина й рішення |
|---|---|
| «Модель … недоступна» (404) | Google змінює й закриває моделі. Виконайте `python scripts/check_api.py`, оберіть актуальну модель із переліку й задайте `GEMINI_MODELS`. |
| «Ліміт запитів вичерпано» (429) | Вичерпано безкоштовну квоту моделі. Зачекайте, оберіть іншу модель або увімкніть кеш. |
| «Ключ API не прийнято» | Ключ невірний або відкликаний; створіть новий в AI Studio. |
| «Порожня відповідь» | Відповідь заблокована або вичерпано ліміт токенів; спробуйте ще раз чи змініть формулювання. |
| Порожня сторінка у Cloud Shell Web Preview | Запускайте через `scripts/run_cloudshell.sh` (він вимикає CORS/XSRF-перевірку, потрібну за проксі). |

## Обмеження

* Ліміти довжини для платформ — демонстраційні цільові значення (`copygen/config.py`), а не офіційні вимоги майданчиків.
* Перевірка «вигаданих чисел» і мови — евристики, вони лише позначають підозрілі місця.
* Якість текстів залежить від моделі; результат варто перечитати перед публікацією.
* Демо-режим — не ШІ, а шаблон.
